# The generated set, its first scores, and what the clean text showed about the report model

Written 2026-10-27. Data: `~/datasets/synth_v1` (docs/DATA_LAYOUT.md). Scripts: `scripts/corpus/gen_scripts.py`,
`render_set.py`, `eval_set.py`, `report_set.py`, `hint_insertions.py`. Plans: docs/plans/LYAPUNOV_STT_PLAN.md Phase 0,
FINETUNE_PLAN.md section 2.

## The set

200 radio reports generated from sampled facts in the corpus' phrasing, seed 1. Families: trauma 27, stroke 25,
fragments 25, other medical 19, sepsis 18, STEMI 15, chest pain without ST changes 15, pediatric 14, endocrine 14,
cardiac arrest 11, psychiatric 9, obstetric 8. Full reports run 75 to 127 words by family (STEMI longest, pediatric
shortest); fragments 13. A priority is stated in 135 scripts (1: 50, 2: 64, 3: 21) and absent in 65; an ETA is
stated in 165 and absent in 35. Every unstated fact is a null demand in the gold (allergies, code status, ETA, GCS
breakdown, oxygen delivery), so the barrier rules have test cases. Splits by script, stratified by family: train 140,
validation 30, test 30. The gold is the `tests/gold` format plus `stated` (priority, ETA, alert words) and `marker`.

The generator checks itself: a gold field whose fact the text does not contain is refused. That caught three template
bugs on the first run (an aspirin dose variant, a rhythm that disagreed with the rate, treatment lines read before the
vitals). Two more came from scoring (below). Known flaw kept in this set: 24 scripts say "a 81-year-old".

Rendered: the Piper voice reads the spoken form (abbreviations spelled out), 16 kHz, then `radioize` to the corpus
spectrum with the 4.6 kHz wall, -26 dBFS, soft limiter, and the real feed-4390 floor at SNR 20, 15, 10 and 5 dB, plus
the channel with no noise ("inf"). 1000 clips, 1.5 GB, 30 minutes on the Jetson; each clip is also a one-burst
call-set so replay mode plays it with `HANDOFF_CALLSETS=~/datasets/synth_v1/callsets`. Cloned voices (XTTS) are not
rendered: 8 minutes per script on this CPU; they wait for the second Jetson.

## The report model on perfect text (the pasted-text path)

`report_set.py --split test --clean`: the 30 test scripts' texts straight into the app's pipeline, qwen3:4b-instruct
pinned, rules as of commit 47a6a5f (before the morning's grounding changes), 55 s per report.

| transcript | reports | weighted | recall | precision | halluc / report | alert type | level | ETA |
|---|---|---|---|---|---|---|---|---|
| clean | 30 | 96.4 | 98.4 | 96.3 | 0.43 | 93 % | 100 % | 100 % |

Level and ETA are right in every report where one was stated, and null in every report where none was. What failed,
by field, over the 30 reports (weight in brackets):

| failure | count | what it was |
|---|---|---|
| GCS breakdown invented [3] | 4 | "GCS is 9" came back as "9 (Eye: 3, Verbal: 4, Motor: 2)"; the same for 13 and 3 |
| intervention omitted [3] | 4 | the c-collar / backboard sentence and one oxygen device left out |
| activation request invented [2] | 3 | "endocrine service", "trauma team" x2 for crews that asked for nothing |
| intervention invented [3] | 3 | "cervical collar, applied" in a seizure and a stroke report; "vital signs assessment" |
| alert type wrong [3] | 2 | sepsis with glucose 246 and a dehydrated 3-year-old with CBG 108 both called ENDOCRINE |
| rhythm dropped [1] | 2 | "sinus tach" not carried anywhere |
| "room air" invented [1] | 2 | oxygen delivery never stated |
| EMS drug as home med [3] | 1 | the aspirin and nitro the crew gave, listed under medications |
| allergies null [3] | fixed in 47a6a5f | "No known allergies" read as nothing said, in both of the first two reports |

Three of these were the gold's fault and are corrected (oxygen by a device is an intervention; "on blood thinners" is
a medication; "diabetic emergency" names the condition); the run was rescored against the corrected gold, which is the
table above.

What changed in the pipeline today, each with a test, each noted in the report's assumptions when it fires:

1. A spoken "no known allergies" / NKDA fills a null allergies field; a spoken DNR, DNI, full code, no code or
   comfort care fills a null code status. Nothing is filled when nothing was said.
2. A GCS breakdown is removed when the transcript has no eyes/verbal/motor cue.
3. A home medication that is a drug listed under the interventions, and that the transcript mentions only in
   sentences without a home-medication cue, is removed.
4. An intervention none of whose content words occurs in the transcript is removed.
5. activation_requested is cleared when the transcript has no request cue.
6. "room air" is removed from SpO2 when it was never said.
7. (From ROUND2.md candidate 2.) An alert word negated in its sentence, answered "no", or named as history no longer
   turns an UNCLEAR report into that type.

The clean-text run is repeated with these rules after the baseline chain finishes (label `clean_postfix`); the
before-and-after is the first H2 measurement of FINETUNE_PLAN.md (hallucinations with the rules on and off).

The two ENDOCRINE calls are the model's, not the rules': a glucose value in the vitals pulls the 4B model toward
ENDOCRINE whatever the complaint. That is the case the fine-tuning plan names (sepsis-as-ENDOCRINE); the generated
training pairs now contain it.

## Transcriber baselines on the test split (Piper voice, 150 clips)

Tables are appended as each run finishes. Local faster-whisper on the CPU (no CUDA build of ctranslate2 on this
Jetson): medium 0.8x real time, small 0.35x. The Groq rows wait for a key (the secrets file has an empty
GROQ_API_KEY). WER is edits over reference words against the written script (`SY017.txt`, not the spoken form);
MTER is the share of the 149 term occurrences from `terms.txt` that the transcript lacks; "halluc" is content words
in the transcript that the script does not contain; "dropped tail" is the share of the script's last 20 % of words
missing from the transcript.

Scorer note: the first medium pass counted "A-fib" (the transcriber's spelling) against the script's "AFib" and
"micrograms" against "mcg" as errors, six and four occurrences per SNR. `score_callsets.normalize` now folds both,
and every eval folder is rescored from its saved transcripts (`eval_set.py --rescore <folder>`) so the tables below
share one scorer. The medium numbers moved from 5.4/13.0 to 4.8/10.0 (WER/MTER, clean).

Where the clean-audio errors come from (147 edit spans over 2729 reference words, all 30 clips):

| kind | examples (script -> transcript) | spans |
|---|---|---|
| Piper's pronunciation, not the recogniser | "on scene" -> "unseen" (6), "ETA" -> "et of", "et to", "etia", "etf" (9), "are" -> "or" (4), "sat" -> "set" (3), "right AC" -> "ritice" | ~25 |
| drug names | lisinopril -> "pellicinopril", Eliquis -> "deliquase", Xarelto -> "xeryl tol", "POLST" -> "pulsed" | ~8 |
| a short word lost or swapped | "squad" -> "quad", "medic" -> "medex", "vitals" -> "bidels", "resp rate" -> "respiration" | ~10 |
| numbers | "119" -> "190", "84" -> "e4" | 2 |

The ETA and "on scene" rows are the voice: Piper reads "E T A" with a glide the recogniser hears as "et of", and
runs "on scene" together. They would not appear with a human reader, so the Piper-only numbers overstate the clean
WER by about a point. The drug-name misses are the real target for the corrector and the hint (the hint lists the
drugs; medium still misses lisinopril three times out of three). Terms missed at clean, after the scorer fix:
lisinopril 3, ST elevation 2, rhonchi 2, Eliquis 2, then one each of CAD, c-spine, Xarelto, CHF, febrile,
levothyroxine, diltiazem, atorvastatin, metoprolol, large-bore.

Hint insertions (`hint_insertions.py`): none. No clip at any SNR contains a hint phrase its script lacks, so the
hint is not planting vocabulary on this voice.
